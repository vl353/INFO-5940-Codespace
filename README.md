## 💡 AI Document Assistant
This is an interactive web application built using Streamlit and LangChain, allowing users to "chat" with their own documents. This application uses Retrieval Augmented Generation (RAG) technology to ensure that all answers are entirely based on the content of the uploaded file.

## ✨ Overview of Core Functions 
1. 📄 Multi format document upload: Users can upload one or more documents in formats of. txt and. pdf. The backend is powerful enough to handle various text encodings.
2. ⚙️ Configurable processing parameters: Before processing the document, users can fine tune parameters such as 'Chunk Size' and 'Chunk Overlap' to control how document text is segmented for the knowledge base.
3. 📊 Summary of Processing Results: After the document processing is completed, the application will immediately provide a clear summary, including the number of processed files, total pages/documents, and the final number of knowledge blocks created. This allows users to be confident that their documents have been successfully indexed.
4. 💬 Interactive chat interface: Users can ask questions using natural language through a familiar chat interface. The application will find the most relevant information from the document and generate a concise answer.
5. 🔍 Answer source citation: Each answer generated by AI is accompanied by a list of source documents it references, providing transparency and facilitating user verification.
6. 📑 Document Content Preview: There is a dedicated tab within the application that allows users to select any uploaded document from a drop-down menu and view its entire text content directly within the application. This feature is very practical, as users can quickly check the original text without leaving the application.
7. 🔄 Global Control: The sidebar contains easy-to-use buttons that can 'clear conversation history' or 'reset the system', making it convenient for users to restart at any time.

##  🚀 Run on GitHub Codespaces
### Step 1: Verify environment 
Select Python Environments, choose Python 3.11.13. Run the code block to check setup. 

### Step 2: Install dependency libraries
After starting Codespace, open a new terminal. By default, the required Python libraries are not installed. So I run the following command to install them:
   ```bash
   pip install --upgrade streamlit openai langchain-openai langchain-community langchain-chroma pypdf
   ```

### Step 3: Set API Key
To run the Streamlit app and set up the key at the same time, run both commands together:
   ```bash
   API_KEY="your_actual_API_KEY" streamlit run rag_web_app.py
   ```
